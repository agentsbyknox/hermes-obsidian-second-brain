# Memory Protocol

## Promotion ladder
| Signal | Destination |
|---|---|
| Stable preference or fact needed every session | Built-in memory (USER.md / MEMORY.md) |
| Reusable procedure | A skill |
| Durable knowledge or research | A vault note |
| A decision and why | [[Decision Log]] |
| One-off task progress | Let it die with dignity |
## Rules
- The agent PROPOSES (into `00 Inbox/`); Atlas APPROVES. Nothing becomes canon without review.
- No secrets, no raw transcripts.
