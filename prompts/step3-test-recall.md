# Step 3: test recall (with receipts)

After adding the SOUL paragraph, start a new session and ask something only your notes can answer, for example:

```text
What did we decide about thumbnails, and why?
```

A good answer cites the note it used, e.g. `Second Brain: 60 Decisions/Decision Log.md`. Then ask about the deliberately stale note:

```text
What camera settings do I use?
```

It should tell you `Old camera settings` may be out of date.
