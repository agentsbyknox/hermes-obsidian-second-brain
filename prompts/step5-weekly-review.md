# Step 5: the weekly review

Once a week, send:

```text
Weekly review. Open this week's capture proposals in my vault's 00 Inbox. [Say which you approve and where each goes.] Use my frontmatter schema with last_updated today, then mark each proposal as promoted. Show me what changed in a short table.
```

Use the promotion ladder in the main README to decide where each item goes. Anything you don't approve stays in the Inbox, and recall ignores it.

Optional: make this a weekly cron job too, but have it produce a *shortlist* for you to approve, never promote things itself.
